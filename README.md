# Simple ERP：小型貿易商進銷存管理系統

一套給小型進口／批發商使用的 ERP 系統，目前實際用於家中的水產貿易生意。
將原本用紙本和 Excel 記錄的進貨、出貨、庫存、應收應付帳款整合到同一個系統，並能直接產出請款單和報表。

## 功能

| 分頁 | 功能 |
| --- | --- |
| 出貨 | 登記出貨紀錄，依年月查詢，可修改和刪除 |
| 進貨 | 登記進貨紀錄，支援多幣別（外幣進貨） |
| 庫存 | 依進出貨自動計算帳面庫存，並可登記實際盤點數量、追蹤損耗 |
| 基礎資料設定 | 管理廠商、貨品、顧客、幣別，以及每月匯率 |
| 儀表板 | 每月出貨、進貨、毛利、淨利（扣除薪水、租金等支出），以及損耗估值與公斤數走勢圖；可切換近 12 個月／5 年／10 年 |
| 應收／應付帳款 | 追蹤各客戶未收款；多筆外幣進貨可合併付款，依實際匯出台幣金額自動分配 |
| 匯出／匯入 | 產生 Excel 格式的請款單、出貨表、進貨表；可下載範本，批次匯入資料並在匯入前檢查格式 |

## 技術

- **Python**
- **Gradio**：網頁介面
- **MySQL**（PyMySQL）：資料儲存（進貨、出貨、庫存盤點、收付款、匯率等 12 張資料表）
- **pandas / openpyxl**：資料處理與 Excel 報表輸出

## 設計重點

- **多幣別與匯率**：進貨可使用外幣，依每月匯率換算台幣，計算毛利與應付帳款
- **合併付款分配**：一次付款可對應多筆進貨，系統依實際付出的台幣金額分配到各筆紀錄
- **輸入驗證**：數量、金額等欄位會檢查格式，錯誤或負數不會被默默存成 0；批次匯入前先預覽並逐列檢查
- **設定與程式分離**：資料庫密碼、店名等放在 `.env`，同一份程式碼可以同時用於實際營運和展示

## 安裝與執行

1. 安裝套件

   ```bash
   pip install -r requirements.txt
   ```

2. 建立資料庫（MySQL）

   ```bash
   mysql -u root -p -e "CREATE DATABASE erp_demo CHARACTER SET utf8mb4"
   mysql -u root -p erp_demo < schema.sql
   ```

3. 設定連線：複製 `.env.example` 並改名為 `.env`，填入自己的資料庫密碼

4. 啟動

   ```bash
   python Index.py
   ```

   瀏覽器打開終端機顯示的網址（預設為 http://127.0.0.1:7860）。

## 專案結構
